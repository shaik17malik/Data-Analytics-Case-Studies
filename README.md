## 🎓 Case Study 01: Student Outcomes Analysis

**Scenario:** EduPulse University wants to investigate student performance and address concerns about graduation outcomes.

**Role:** Junior Data Analyst

### Tasks Performed
- Loaded and explored the student dataset.
- Examined student marks and attendance.
- Calculated average marks and attendance.
- Identified missing values.
- Detected and removed duplicate records.
- Filled missing marks using the mean.
- Handled invalid attendance percentages.
- Checked unusual age values.
- Corrected negative marks.

### Skills Demonstrated
Python, Pandas, missing-value handling, duplicate removal, and data cleaning.

## 🛒 Case Study 02: E-Commerce Sales Performance

**Scenario:** SwiftCart Retail wants to optimize its inventory by understanding sales performance across product categories.

**Role:** Sales Operations Analyst

### Tasks Performed
- Loaded and explored the sales dataset.
- Calculated total sales using price and quantity.
- Grouped sales by product category.
- Identified the highest-selling category.
- Calculated average customer ratings.
- Filtered products with ratings above 4.
- Created category-wise sales bar charts.
- Visualized product price distribution.
- Applied a 15% discount calculation for electronics.

### Skills Demonstrated
Pandas, calculated columns, GroupBy, filtering, and Matplotlib.

## 🎬 Case Study 03: Movie Market Analysis

**Scenario:** CineData Studios wants to analyze historical movie data to support production planning.

**Role:** Media Strategy Analyst

### Tasks Performed
- Loaded and explored movie ratings data.
- Removed duplicate records.
- Handled invalid IMDb ratings.
- Checked invalid movie durations.
- Handled negative box-office values.
- Calculated average IMDb ratings.
- Analyzed average ratings by genre.
- Identified the highest-rated genre.
- Compared genre-wise box-office revenue.
- Visualized IMDb rating distribution.
- Classified movies with IMDb ratings of 8 or higher as hits.
- Calculated total hit movies and hit percentage.

### Skills Demonstrated
Data cleaning, aggregation, categorical analysis, visualization, and conditional classification.

## 👥 Case Study 04: HR & Talent Insights

**Scenario:** Nexus Corp wants to examine salary patterns and identify high-performing employees.

**Role:** People Analytics Consultant

### Tasks Performed
- Explored employee performance data.
- Checked missing and duplicate values.
- Calculated average monthly salary.
- Compared average salaries by department.
- Identified the department with the highest average salary.
- Classified employees with performance scores of 7 or higher as high performers.

## 📈 Data Analytics Workflow

The general workflow followed across these case studies is:

1. Understand the problem statement.
2. Import the required Python libraries.
3. Load the dataset.
4. Explore the dataset structure.
5. Check missing and duplicate values.
6. Clean data where required.
7. Calculate analytical metrics.
8. Filter and group data.
9. Create visualizations.
10. Review the analytical results.

Not every notebook performs every step.

## ▶️ How to Run the Case Studies

### Option 1: Google Colab

1. Open https://colab.research.google.com/
2. Upload the required `.ipynb` notebook.
3. Upload its corresponding CSV dataset.
4. Update the dataset path in the notebook if needed.
5. Run the cells in order.

### Option 2: Jupyter Notebook

1. Install Python and Jupyter Notebook.
2. Install the required libraries:

```bash
pip install pandas matplotlib notebook
```

3. Download or clone this repository.
4. Open the required notebook.
5. Check the dataset file path.
6. Execute the notebook cells in order.
